# RomanMAST Roadmap

This repository represents the conceptual infrastructure for hosting key historical microlensing datasets at the Mikulski Archive for Space Telescopes (MAST) to support the Nancy Grace Roman Space Telescope. 

While the proposals themselves are complete, realizing this vision as an active component of discovery requires ongoing evolution. Below is the roadmap for future development:

## Future Work

- **Roman Event Cross-Matching Tools:** Developing lightweight, user-friendly Python tools to systematically cross-reference Roman Galactic Bulge Time-Domain Survey (GBTDS) detections against historical OGLE/KMTNet data in real-time.
- **Candidate Black Hole Ranking:** Implement a weighted scoring system that analyzes Gaia astrometry, mass estimates, and timescale properties to prioritize the strongest isolated stellar remnant candidates for immediate Roman follow-up.
- **Automated Light-Curve Ingestion:** Build automated scripts that gather fragmented light curves from ground-based surveys into cohesive, Roman-ready HLSP (High-Level Science Product) formats automatically.
- **MAST HLSP Formatting Templates:** Standardize metadata dictionaries, table columns, and data types across the three independent catalogs to ensure smooth interoperability within Roman's future data ecosystem framework.

## Community Contributions

As this is a community-driven initiative, we welcome active feedback, discussion, and additional tools that align with these milestones.
